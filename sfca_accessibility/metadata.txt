about=Computes a spatial accessibility index for GP (primary care) supply points against population demand points (centroids of electoral divisions or any polygons) using the two-step floating catchment area method. Catchments are defined by road-network travel time (default 15 minutes) for driving, cycling or walking. Accepts GP locations as CSV / Shapefile / GeoJSON, population polygons as Shapefile / GeoJSON, and a roads line layer. Produces a styled choropleth layer, a GP supply layer with provider-to-population ratios, and an optional A4 print layout (PDF). Includes an independent regression tool relating accessibility to population density, rurality and deprivation. Built for QGIS 4 (Qt6 / PyQt6).
